# Scope

From the meeting with DG Move / CEN
Outcome:
* It must follow the CEN procedures, it’s a CEN project
* We must deliver a TS (technical specification), before 2028
* Including a specification of a single interface description, covering all modes represented in the participating standards/experts
* The TS & specification must be delivered to refer in legislation(s)
* It must be sufficient to support the European travellers for its journeys
* It must be Transmodel compliant, to become interoperable (connectable to other actors)

So, in other (my technical) words:
*  We need to merge the existing standards, taking care of all the basic functions in there (and maybe add some we still have on our backlogs)

# GitHub responses

* must support all interactions between a retailer and a distributor/fare provider for multimodal public transport services

* dedicated enlistment of a device for secure barcode fulfillment
* reach an agreement quickly on the sales process

* How should it relate to other (Transmodel based or de-facto) standards

# Bottom line

* Boundaries: sum of all participating standards (+..)
* Agnostic to external data (NeTEx, DATEX-II, GxFS, …)
